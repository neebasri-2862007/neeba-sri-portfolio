# Student Record Management System

A web application to manage college student academic records digitally.

### Tech Stack
Python, Django 5.0.3, HTML, CSS, Bootstrap, SQLite

### Features
- Custom Email-based Login System
- Dashboard with Total Students, Subjects, and Courses count
- Add, Edit, Delete and View Students, Courses, Subjects
- Between-Dates Report for Students
- ForeignKey Relationship: Course -> Subjects -> Student
- CASCADE Delete Implementation

### How to Run
1. Clone this repo
2. Run `python manage.py runserver`
3. Open `http://127.0.0.1:8000/` in browser
